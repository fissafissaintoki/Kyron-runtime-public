# KYRON Public Trust Model

Ein öffentlich heruntergeladenes Artefakt gilt nur dann als offiziell, wenn:

1. es aus dem offiziellen KYRON-Release stammt,
2. das Release-Manifest vorhanden ist,
3. die SHA-256-Prüfsumme übereinstimmt,
4. die veröffentlichte Version im Changelog geführt wird.

Forks, Reuploads oder veränderte Pakete sind nicht Teil des kanonischen KYRON-Systems.
