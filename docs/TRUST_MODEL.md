# KYRON public trust model

## Canonical authority

Only the repository owner's approved state in
`fissafissaintoki/Kyron-runtime-public` is part of the official public channel.
A fork, reupload, screenshot or modified package is outside that authority.

## Release proof

A downloadable artifact is official only when all of the following are true:

1. it is listed in this repository's changelog;
2. its release manifest has state `PUBLIC_APPROVED`;
3. every required gate is green;
4. the manifest records explicit owner approval and publication authorization;
5. every file matches its SHA-256 digest;
6. the repository's Public Release Gate succeeds.

The manifest proves integrity and approval of published bytes. It does not
prove that an unlisted copy is safe or official.

## Visibility and rights

Public bytes are technically copyable. Visibility is not an open-source
license. The applicable rights policy is recorded in `RIGHTS.md`, and
third-party material remains subject to `THIRD_PARTY_NOTICES.md`.
