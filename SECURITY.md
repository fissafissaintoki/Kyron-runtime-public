# Security policy

## Supported material

Only artifacts explicitly published in this repository are in scope. No
private KYRON system, credential, operator data or internal runtime is hosted
here.

## Reporting a vulnerability

Do not place credentials, personal data, exploit details or other sensitive
material in a public issue.

Use GitHub's private vulnerability reporting channel for this repository when
available. If that channel is not visible, open a minimal issue requesting a
private contact path without including sensitive details.

Include the affected release identifier, file path and SHA-256 digest. A report
does not authorize access to systems or data outside the published release.

## Authenticity concern

If a downloaded artifact does not match its release manifest, do not run it.
Report the release identifier and the observed digest.
