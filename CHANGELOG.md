# Changelog

All notable changes to the public KYRON release channel are recorded here.

## 2026-08-05 — KYRON DJ Operator v0.1

- approved the first public KYRON application release;
- added a free local-first two-deck DJ surface;
- added equal-power mixing, waveforms, BPM tap, cues and bounded sync;
- added local Teacher View audio analysis;
- added set-list and metadata-only session import/export;
- added an installable offline PWA for desktop, iOS and Android;
- added deterministic SHA-256 manifest generation and release verification;
- added guarded GitHub Pages publication from the approved payload;
- confirmed that no credentials or audio files are published.

Public application:

`https://fissafissaintoki.github.io/Kyron-runtime-public/`

## 2026-07-25 — Public channel bootstrap

- initialized the controlled public release repository;
- added the first trust model, manifest schema and safety workflow;
- added explicit rights, security and third-party notices;
- added owner-approved, hash-bound public release manifests.
