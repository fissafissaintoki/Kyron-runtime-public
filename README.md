# KYRON Runtime — Public Release Channel

Dieses Repository ist die öffentliche, kontrollierte Auslieferungsschicht von KYRON.

## Enthalten

- verifizierte Release-Artefakte
- Bedienungsanleitungen
- Screenshots und Demonstrationen
- Changelog
- Release-Manifeste
- SHA-256-Prüfsummen

## Nicht enthalten

- privater KYRON_CORE-Quellcode
- Secrets oder Zugangsdaten
- produktive Runtime-Daten
- Operator-Memory
- NAS-Inhalte
- interne Upgrade- und Entscheidungslogik

## Veränderbarkeit

Außenstehende können den offiziellen Hauptstand nicht direkt verändern. Kopien oder Forks liegen außerhalb des kanonischen KYRON-Systems und erhalten keine Vertrauensstellung.

Vertrauenswürdig ist nur ein Release, dessen Manifest und SHA-256-Prüfsumme mit dem offiziellen Release übereinstimmen.
